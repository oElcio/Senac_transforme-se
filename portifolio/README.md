# Portfólio — Elcio Ferreira

## Descrição

Site de portfólio pessoal de Elcio Ferreira, Desenvolvedor Full Stack em
Recife/PE. Construído no mesmo molde do projeto Recife Conecta: página
única, com HTML5, CSS3, JavaScript puro e Bootstrap 5.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro (vanilla JS)
- Bootstrap 5.3 (via CDN)
- Bootstrap Icons (via CDN)

Nenhuma outra biblioteca, framework ou dependência de instalação foi
utilizada.

## Estrutura de pastas

```
portfolio-elcio/
├── css/
│   └── style.css
├── img/
│   └── README.txt
├── js/
```

## Como executar com o Live Server

1. Abra a pasta `portfolio-elcio` no VS Code.
2. Instale a extensão "Live Server", caso ainda não tenha.
3. Clique com o botão direito no arquivo `index.html`.
4. Selecione "Open with Live Server".
5. O navegador abrirá automaticamente o site.

## Seções da página

- **Sobre** — apresentação, contatos (e-mail, telefone, LinkedIn) e foto.
- **Habilidades** — cards de Front-end, Back-end e Ferramentas.
- **Experiência** — card com a experiência profissional e modal de detalhes.
- **Formação** — formação acadêmica e accordion com cursos/certificações.
- **Contato** — formulário validado por JavaScript (sem envio a servidor).

## Componentes do Bootstrap utilizados

- Navbar responsiva com menu hambúrguer
- Container e sistema de grid (row/col)
- Cards
- Buttons
- Modal
- Accordion
- Formulário (form-label, form-control, form-check)
- Badges
- Classes utilitárias de espaçamento, cor e tipografia
- Bootstrap Icons
